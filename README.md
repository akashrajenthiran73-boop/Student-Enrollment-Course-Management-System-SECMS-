# 🎓 SECMS - Student Enrollment & Course Management System

## 📝 Overview
Welcome to the **SECMS** project repository! Our team built this comprehensive Student Enrollment and Course Management System using **Salesforce**. This application is designed to streamline the process of managing students, courses, instructors, and their enrollments efficiently in a cloud-based CRM environment.

## ✨ Key Features & Implementation
Our team successfully implemented the following Salesforce features in this project:

*   **Custom Lightning App:** Built a dedicated "SECMS" app with a customized, user-friendly interface and optimized page layouts.
*   **Data Modeling:** Created custom objects (`Student`, `Course`, `Instructor`, and `Enrollments`) with appropriate custom fields to store and manage data.
*   **Data Quality:** Configured **Validation Rules** (e.g., verifying `@student.edu` email formats) to ensure clean and accurate data entry.
*   **Relationships:** Utilized **Master-Detail** and **Lookup** relationships to seamlessly connect students, courses, and instructors.
*   **Approval Processes:** Set up an automated approval workflow for new course enrollments.
*   **Automation (Flows):** Implemented **Record-Triggered Flows** to automatically send confirmation emails to students once their enrollment is approved.
*   **Analytics:** Developed Custom **Reports and Dashboards** to visually track business metrics like total enrollments and revenue.
*   **Security:** Configured **Permission Sets** (e.g., "Enrollment Officer") to ensure secure and role-based data access.
